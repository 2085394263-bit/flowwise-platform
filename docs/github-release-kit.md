# GitHub 仓库发布素材

## 仓库简介

基于 Java 25、Spring Boot 3.5 和 Spring AI 的团队项目协作平台，包含角色化工作台、项目审批、任务分派与交付验收，以及带权限过滤的只读 AI 项目助手。

## 建议 Topics

`java` `spring-boot` `spring-ai` `project-management` `task-management` `workflow` `h2-database` `ai-agent`

## 建议仓库名

`flowwise-platform`

## 发布前人工确认

- 选定并添加开源许可证；许可证会决定其他人可以如何使用、修改和分发代码。
- 确认 GitHub 账户名和仓库名，并将 README 构建徽章中的 `OWNER/REPOSITORY` 替换为实际路径。
- 确认首次提交不包含 `data/`、`target/`、`runlogs/`、密钥、个人配置或其他本机数据。项目 `.gitignore` 已忽略这些运行内容。
- 确认公开演示账号只用于本地演示；不要将该应用和固定演示密码直接暴露到公网。
- 确认项目名称、图标和所有资源均可用于公开发布。

## 可粘贴到 GitHub 的 About 描述

面向小团队的 Java 项目协作平台，支持角色权限、项目审批、任务分派与交付验收，并集成按权限读取业务数据的 AI 项目助手。
